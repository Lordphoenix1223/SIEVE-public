# Release provenance and limits

This repository is a curated public snapshot of SIEVE's pre-existing development,
not its complete development history. Earlier private development and review remain
in the original repository; their history was not rewritten or deleted. The snapshot
was prepared on 2026-11-14 from SIEVE commit
`7c176e34f13275837dc27a7f8d724e335e6fcc3d`, which follows the QR3 science work and
the draft frontend export and source-investigation changes. The original project
copyright and MIT license are preserved. The new initial commit records the release
snapshot; it does not assert that all preceding work was created at that time or by
one person without assistance.

To avoid publishing local machine paths and internal development records, this snapshot
omits historical engineering reports, retained development and clean-run archives,
legacy identity replay receipts, and their archive-verification script. The executable
science, input FITS cutouts and hashes, source-investigation evidence, tests, and
reproduction manifests are retained. The release README replaces branch-specific
instructions; the qualification README explains the omitted archives. These omissions
do not change the scientific status of the underlying work.

The QR3 measurements are exploratory. Formal flux uncertainties are conditional, the
Gaia match is tentative, the independent check is inconclusive, and no false-discovery
rate, source identity, moving-object detection, or validated artifact-rejection rate
is established. Some earlier research was conducted independently of a Space Apps
submission; event eligibility is not asserted by this release.
